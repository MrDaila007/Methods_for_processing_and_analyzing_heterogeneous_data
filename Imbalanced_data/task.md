# Методы работы с несбалансированными данными

## Цель работы

Изучить влияние дисбаланса классов на качество классических моделей машинного обучения и сравнить эффективность разных методов балансировки обучающей выборки.

## Данные

Необходимо выбрать табличный набор данных с дисбалансом классов.

Требования к данным:

- задача бинарной классификации;
- наличие выраженного дисбаланса между классами;
- возможность использовать классические алгоритмы машинного обучения.

Возможный источник данных: Kaggle.

## Основные этапы задания

1. Выбрать и загрузить табличный набор данных с дисбалансом классов.
2. Выполнить предварительный анализ данных.
3. Рассчитать коэффициент дисбаланса классов.
4. Построить базовую модель машинного обучения без балансировки данных.
5. Оценить качество базовой модели с помощью метрик:
   - `accuracy`;
   - `balanced accuracy`.
6. Применить методы балансировки обучающей выборки:
   - понижение выборки большинства;
   - повышение выборки меньшинства;
   - комбинация повышения и понижения.
7. Для каждого подхода повторно обучить модель и оценить `accuracy` и `balanced accuracy`.
8. Сравнить результаты и сделать выводы.

## Ожидаемый результат

В результате работы необходимо получить:

- выбранный и подготовленный датасет;
- рассчитанный коэффициент дисбаланса;
- базовую модель без балансировки;
- несколько моделей, обученных после применения методов балансировки;
- таблицу сравнения метрик;
- вывод о том, какие методы лучше подходят для выбранного набора данных.
