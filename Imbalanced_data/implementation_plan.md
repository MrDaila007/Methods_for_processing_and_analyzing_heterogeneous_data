# План реализации: методы работы с несбалансированными данными

## 1. Выбор датасета

- Создать рабочий Python Notebook (`.ipynb`) для эксперимента.
- Выбрать табличный датасет для бинарной классификации с выраженным дисбалансом классов.
- Подходящие варианты:
  - credit card fraud detection;
  - churn prediction;
  - medical diagnosis;
  - default payment prediction.
- Скачать данные и сохранить их в рабочей папке проекта.
- Описать источник данных, целевую переменную и смысл классов.

## 2. Первичный анализ данных

- Загрузить датасет с помощью `pandas`.
- Проверить размер данных, типы признаков и пропущенные значения.
- Определить целевую переменную.
- Посчитать количество объектов каждого класса.
- Визуализировать распределение классов.

## 3. Расчет коэффициента дисбаланса

- Рассчитать коэффициент дисбаланса:
  - отношение количества объектов мажоритарного класса к количеству объектов миноритарного класса.
- Зафиксировать долю каждого класса в процентах.
- Кратко объяснить, почему обычная `accuracy` может быть недостаточной при таком распределении классов.

## 4. Подготовка признаков

- Разделить данные на признаки `X` и целевую переменную `y`.
- Обработать пропуски, если они есть.
- Закодировать категориальные признаки.
- При необходимости масштабировать числовые признаки.
- Разделить данные на обучающую и тестовую выборки с использованием стратификации.

## 5. Базовая модель без балансировки

- Выбрать классический алгоритм машинного обучения:
  - `LogisticRegression`;
  - `RandomForestClassifier`;
  - `GradientBoostingClassifier`.
- Обучить модель на исходной обучающей выборке.
- Оценить качество на тестовой выборке:
  - `accuracy`;
  - `balanced accuracy`;
  - дополнительно можно посчитать `precision`, `recall`, `F1-score` и матрицу ошибок.
- Сохранить результаты как базовую точку сравнения.

## 6. Методы балансировки

- Применить понижение обучающей выборки:
  - `RandomUnderSampler`.
- Применить повышение обучающей выборки:
  - `RandomOverSampler`;
  - при необходимости `SMOTE`.
- Применить комбинированный подход:
  - `SMOTEENN`;
  - или `SMOTETomek`.
- Выполнять балансировку только на обучающей выборке, чтобы не допустить утечки данных.

## 7. Обучение и сравнение моделей

- Для каждого варианта балансировки обучить одну и ту же модель.
- Оценить качество на неизмененной тестовой выборке.
- Сформировать итоговую таблицу:
  - метод обработки данных;
  - распределение классов после балансировки;
  - `accuracy`;
  - `balanced accuracy`;
  - дополнительные метрики при необходимости.
- Сравнить, как меняется качество по сравнению с базовой моделью.

## 8. Итоговый анализ

- Определить, какой метод дал наилучшую `balanced accuracy`.
- Проверить, не произошло ли сильное падение обычной `accuracy`.
- Объяснить компромисс между качеством на большинстве и меньшинстве.
- Сделать вывод о том, какой подход лучше использовать для выбранной задачи.
