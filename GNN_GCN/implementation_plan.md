# План реализации: MLP, GNN и GCN для Facebook Page-Page

## 1. Подготовка окружения

- Создать рабочий Python Notebook (`.ipynb`) для эксперимента.
- Установить и подключить библиотеки:
  - `torch`;
  - `torch_geometric`;
  - `numpy`;
  - `pandas`;
  - `matplotlib`;
  - `scikit-learn`.
- Зафиксировать `random_state` и seed для `torch`, чтобы результаты были воспроизводимыми.

## 2. Загрузка датасета

- Загрузить Facebook Page-Page через `torch_geometric.datasets`.
- Извлечь объект графа `data`.
- Проверить основные характеристики:
  - число узлов;
  - число ребер;
  - размерность признаков;
  - число классов;
  - распределение классов.
- Убедиться, что признаки узлов и метки корректно загружены.

## 3. Подготовка разбиения данных

- Создать маски для обучающей, валидационной и тестовой выборок.
- Использовать стратифицированное разбиение, если это удобно для выбранной реализации.
- Сохранить одинаковое разбиение для всех моделей.
- Проверить, что все модели обучаются и тестируются на одних и тех же узлах.

## 4. Реализация MLP

- Реализовать MLP как базовую модель без использования структуры графа.
- Использовать только матрицу признаков узлов `x`.
- Возможная архитектура:
  - входной линейный слой;
  - `ReLU`;
  - `Dropout`;
  - выходной линейный слой на число классов.
- Обучить модель с функцией потерь `CrossEntropyLoss`.
- Сохранить метрики на обучающей, валидационной и тестовой выборках.

## 5. Реализация GNN

- Реализовать графовую модель с агрегацией сообщений от соседей.
- В качестве слоя можно использовать `SAGEConv`, `GraphConv` или другую базовую графовую операцию из PyTorch Geometric.
- Модель должна использовать:
  - признаки узлов `x`;
  - структуру графа `edge_index`.
- Настроить количество слоев, скрытую размерность и `Dropout`.
- Обучить модель и сохранить метрики.

## 6. Реализация GCN

- Реализовать модель на основе `GCNConv`.
- Использовать архитектуру из двух или трех графовых сверточных слоев.
- Добавить `ReLU` и `Dropout` между слоями.
- Обучить GCN на том же разбиении данных.
- Сохранить метрики качества и историю обучения.

## 7. Оценка качества

- Для каждой модели рассчитать:
  - `accuracy`;
  - `macro F1`;
  - `weighted F1`.
- Дополнительно построить матрицу ошибок для лучшей модели.
- Сформировать таблицу сравнения:
  - модель;
  - число параметров;
  - лучшая валидационная метрика;
  - тестовая метрика.

## 8. Визуализация обучения

- Построить графики изменения функции потерь по эпохам.
- Построить графики изменения accuracy или F1-score по эпохам.
- Сравнить скорость сходимости MLP, GNN и GCN.

## 9. Анализ результатов

- Сравнить MLP с графовыми моделями и определить, дает ли структура графа прирост качества.

- Проанализировать возможные причины различий:
  - качество признаков узлов;
  - плотность и связность графа;
  - влияние соседей на класс узла.
