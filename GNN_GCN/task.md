# MLP, GNN и GCN для набора Facebook Page-Page

## Цель работы

Реализовать и сравнить три подхода к классификации узлов графа на наборе данных **Facebook Page-Page**:

- многослойный перцептрон (**MLP**);
- графовую нейронную сеть общего вида (**GNN**);
- графовую сверточную сеть (**GCN**).

## Данные

Используется графовый набор данных **Facebook Page-Page**.

В этом наборе:

- узлы соответствуют страницам Facebook;
- ребра отражают связи между страницами;
- признаки описывают свойства узлов;
- целевая переменная задает класс страницы.

## Основная задача

Необходимо решить задачу классификации узлов и сравнить качество моделей, которые используют разные объемы структурной информации:

- MLP использует только признаки узлов и не учитывает структуру графа;
- GNN использует признаки узлов и сообщения от соседей;
- GCN использует сверточную агрегацию по графу.

## Требования к реализации

1. Загрузить набор данных Facebook Page-Page.
2. Подготовить разбиение на обучающую, валидационную и тестовую выборки.
3. Реализовать модель MLP.
4. Реализовать графовую нейронную сеть.
5. Реализовать модель GCN.
6. Обучить все модели в одинаковых условиях.
7. Сравнить качество моделей по метрикам классификации.
8. Сделать вывод о влиянии графовой структуры на качество предсказаний.

## Ожидаемый результат

В результате работы необходимо получить:

- код загрузки и подготовки графового датасета;
- обученные модели MLP, GNN и GCN;
- таблицу сравнения качества;
- графики динамики обучения;
- выводы о том, какая архитектура лучше подходит для данного набора данных.
