# Гиперпараметры
В методе k-ближайших соседей ключевой гиперпараметр — k: сколько соседей учитывать.
При k=1 — модель переобучается,
При большом k — сглаживает детали.
Чтобы выбрать гиперпараметры, вводят валидационную выборку:
Данные делят на train / val / test,
Или используют k-fold кросс-валидацию, особенно если данных мало.
