# План реализации: интерпретация ИИ-моделей

## 1. Подготовка окружения

- Создать рабочий Python Notebook (`.ipynb`) для эксперимента.
- Подключить библиотеки: `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`, `lime`, `shap`.
- Зафиксировать `random_state` для воспроизводимости результатов.

## 2. Генерация синтетических данных

- Сгенерировать табличные признаки:
  - несколько информативных числовых признаков;
  - несколько шумовых признаков.
- Сгенерировать текстовые эмбеддинги фиксированной размерности, например 16, 32 или 50 признаков.
- Задать функцию формирования целевой переменной:
  - часть табличных признаков должна положительно или отрицательно влиять на класс;
  - часть координат текстового эмбеддинга должна также влиять на класс;
  - добавить случайный шум.
- Сформировать бинарную целевую переменную через порог или вероятностное распределение.
- Создать таблицу с понятными именами признаков, например `tab_age`, `tab_score`, `emb_0`, `emb_1`.

## 3. Подготовка обучающей выборки

- Разделить данные на обучающую и тестовую выборки.
- При необходимости выполнить масштабирование признаков для LIME.
- Сохранить список признаков по модальностям:
  - `tabular_features`;
  - `text_embedding_features`.

## 4. Обучение модели

- Обучить модель бинарной классификации:
  - `RandomForestClassifier` или `GradientBoostingClassifier`.
- Оценить качество на тестовой выборке:
  - `accuracy`;
  - `precision`;
  - `recall`;
  - `F1-score`;
  - `ROC-AUC`.
- Убедиться, что модель действительно использует информативные признаки.

## 5. Локальная интерпретация с помощью LIME

- Настроить `LimeTabularExplainer` для объединенного пространства признаков.
- Выбрать несколько объектов из тестовой выборки:
  - уверенно предсказанный положительный класс;
  - уверенно предсказанный отрицательный класс;
  - объект около границы решения.
- Получить LIME-объяснения для выбранных объектов.
- Отобразить признаки, которые сильнее всего повлияли на каждое предсказание.

## 6. Интерпретация с помощью SHAP

- Выбрать подходящий SHAP-explainer для обученной модели.
- Рассчитать SHAP-значения для тестовой выборки.
- Построить графики:
  - `summary_plot` для глобальной важности признаков;
  - `bar plot` для средней абсолютной важности;
  - локальное объяснение для отдельных объектов.
- Сравнить SHAP-выводы с LIME-объяснениями.

## 7. Агрегация вкладов по модальностям

- Для каждого объекта посчитать сумму или среднее абсолютное значение вкладов признаков внутри каждой модальности.
- Рассчитать глобальный вклад:
  - табличной модальности;
  - текстовой модальности.
- Построить диаграмму сравнения вкладов модальностей.
- Проверить, совпадает ли результат с логикой генерации целевой переменной.

## 8. Итоговый отчет

- Описать схему генерации данных.
- Привести параметры модели и метрики качества.
- Показать локальные LIME- и SHAP-интерпретации.
- Показать глобальную важность признаков и модальностей.
- Сделать вывод о том, насколько корректно LIME и SHAP восстанавливают заданную структуру влияния признаков.
