# Интерпретация ИИ-моделей

## Цель работы

Реализовать интерпретацию предсказаний модели машинного обучения, работающей с гетерогенными данными: табличными признаками и текстовыми эмбеддингами.

Необходимо использовать методы **LIME** и **SHAP** для локального и глобального анализа важности признаков, а также выполнить агрегацию вкладов отдельных признаков для оценки влияния каждой модальности на итоговое предсказание.

## Данные

Данные генерируются синтетически.

В наборе должны быть представлены две модальности:

- табличные признаки;
- текстовые эмбеддинги.

Целевая переменная должна имитироваться как функция от выбранных информативных признаков с добавлением шума.

## Модель

Задача решается как бинарная классификация.

В качестве базового алгоритма можно использовать один из классических ансамблевых методов:

- случайный лес;
- градиентный бустинг.

## Требования к интерпретации

1. Обучить модель на объединенном пространстве табличных признаков и текстовых эмбеддингов.
2. Выполнить локальную интерпретацию отдельных предсказаний с помощью LIME.
3. Выполнить локальную и глобальную интерпретацию модели с помощью SHAP.
4. Сгруппировать вклады признаков по модальностям:
   - вклад табличных признаков;
   - вклад текстовых эмбеддингов.
5. Сравнить важность отдельных признаков и важность модальностей.

## Ожидаемый результат

В результате работы необходимо получить:

- синтетический датасет с гетерогенными признаками;
- обученную модель бинарной классификации;
- метрики качества модели;
- LIME-интерпретации отдельных объектов;
- SHAP-графики локальной и глобальной важности;
- оценку вклада каждой модальности в итоговое предсказание;
- выводы о том, какие признаки и модальности сильнее всего влияют на модель.
