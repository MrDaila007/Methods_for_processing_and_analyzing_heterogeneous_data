# COCO Subset Dataset для сравнения YOLO-World и YOLOv8

Эта директория предназначена для хранения подмножества датасета COCO для сравнения моделей YOLO-World и YOLOv8.

## Структура директорий

```
coco_subset/
├── coco_subset.yaml      # Конфигурационный файл датасета
├── images/
│   └── train/            # Изображения для обучения/валидации (минимум 10 изображений)
└── labels/
    └── train/            # Аннотации в формате YOLO (по одному .txt файлу на изображение)
```

## Подготовка датасета

### Вариант 1: Использование существующих изображений из demo

Если у вас нет готового датасета COCO, вы можете использовать изображения из `data/demo/` и создать для них простые аннотации:

1. Скопируйте несколько изображений в `images/train/`
2. Создайте соответствующие файлы аннотаций в `labels/train/` (формат YOLO: `class_id x_center y_center width height`, все значения нормализованы от 0 до 1)

### Вариант 2: Загрузка подмножества COCO

1. Скачайте подмножество COCO с [официального сайта](https://cocodataset.org/#download)
2. Конвертируйте аннотации из формата COCO JSON в формат YOLO
3. Разместите изображения в `images/train/` и аннотации в `labels/train/`

### Формат аннотаций YOLO

Каждый файл `.txt` в `labels/train/` должен соответствовать изображению с тем же именем в `images/train/`.

Формат строки в файле аннотации:
```
class_id x_center y_center width height
```

Где:
- `class_id` - номер класса (0-79 для COCO)
- `x_center`, `y_center`, `width`, `height` - координаты и размеры bounding box, нормализованные от 0 до 1

Пример:
```
0 0.5 0.5 0.3 0.4
16 0.2 0.3 0.1 0.15
```

Это означает:
- Объект класса 0 (person) в центре изображения
- Объект класса 16 (dog) в левой верхней части

## Минимальные требования

Для сравнения моделей достаточно:
- **10 изображений** в `images/train/`
- **Соответствующие аннотации** в `labels/train/`
- Изображения должны содержать объекты из классов COCO

## Использование

После подготовки датасета запустите ячейку сравнения моделей в ноутбуке. Код автоматически:
- Загрузит конфигурацию из `coco_subset.yaml`
- Вычислит mAP@0.5 для обеих моделей
- Измерит FPS на тестовых изображениях
