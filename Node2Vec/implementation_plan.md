# План реализации: рекомендательная система фильмов на основе Node2Vec

## 1. Подготовка окружения

- Создать рабочий Python Notebook (`.ipynb`) для эксперимента.
- Подключить библиотеки: `pandas`, `numpy`, `networkx`, `node2vec`, `gensim`, `scikit-learn`, `matplotlib`.
- Проверить наличие данных MovieLens 100k в папке `ml-100k`.

## 2. Загрузка и первичная обработка данных

- Загрузить файл `ml-100k/u.data` с колонками `user_id`, `movie_id`, `rating`, `timestamp`.
- Загрузить файл `ml-100k/u.item` с названиями фильмов и жанровыми признаками.
- Проверить количество пользователей, фильмов и рейтингов.
- Удалить дубликаты и убедиться, что идентификаторы фильмов корректно сопоставляются с названиями.

## 3. Построение графа фильмов

- Оставить только положительные взаимодействия: `rating >= 4`.
- Для каждого пользователя получить список понравившихся фильмов.
- Для каждой пары фильмов внутри списка пользователя увеличить счетчик совместного появления.
- Оставить пары фильмов с числом совместных положительных оценок не меньше `20`.
- Построить неориентированный взвешенный граф:
  - узлы - `movie_id`;
  - ребра - пары фильмов;
  - вес ребра - число совместных положительных оценок.
- Проверить итоговое число узлов и ребер.

## 4. Анализ графа

- Посчитать базовые характеристики графа: число компонент связности, распределение степеней, средний вес ребра.
- Найти наиболее связанные фильмы.
- Визуализировать небольшой подграф для интерпретации структуры.

## 5. Обучение Node2Vec

- Настроить параметры Node2Vec:
  - размерность эмбеддингов;
  - длину случайного блуждания;
  - количество блужданий;
  - параметры `p` и `q`;
  - окно контекста.
- Обучить модель на построенном графе.
- Сохранить эмбеддинги фильмов для дальнейшего использования.

## 6. Формирование рекомендаций

- Для выбранного фильма найти ближайшие фильмы в пространстве эмбеддингов по cosine similarity.
- Сопоставить `movie_id` с названиями фильмов из `u.item`.
- Реализовать функцию `recommend_movies(movie_title, top_k)`.
- Вывести примеры рекомендаций для нескольких популярных фильмов.

## 7. Оценка и интерпретация результата

- Проверить, совпадают ли рекомендации с жанрами и общей тематикой исходных фильмов.
- Сравнить результаты при разных значениях `p` и `q`.
- Описать, как меняются рекомендации при смещении Node2Vec к BFS- или DFS-подобным обходам.

## 8. Итоговый отчет

- Описать логику построения графа.
- Привести параметры Node2Vec.
- Показать примеры рекомендаций.
- Сделать выводы о применимости графового подхода для рекомендательных систем.
