# Разработка рекомендательной системы фильмов на основе Node2Vec

## Цель работы

Построить рекомендательную систему фильмов с использованием подхода **Graph-based Learning**. Фильмы необходимо представить как узлы графа, а связи между ними должны отражать скрытое семантическое сходство, выявленное через поведение пользователей.

В отличие от традиционной коллаборативной фильтрации, основной акцент делается на графовом представлении данных и обучении эмбеддингов фильмов с помощью алгоритма **Node2Vec**.

## Данные

Используется набор данных **MovieLens 100k**:

- источник: <https://files.grouplens.org/datasets/movielens/ml-100k.zip>;
- `u.data` - рейтинги пользователей в формате `user_id`, `movie_id`, `rating`, `timestamp`;
- `u.item` - информация о фильмах: `movie_id`, `title`, жанры и дополнительные признаки.

## Требования к построению графа

1. Выполнить фильтрацию рейтингов: оставить только высокие оценки `rating >= 4`.
2. Для каждой пары фильмов посчитать число пользователей, которым понравились оба фильма.
3. Создать взвешенное ребро между фильмами, если число совместных положительных оценок не меньше `20`.
4. Получить граф фильмов, где:
   - узлы - фильмы;
   - ребра - совместные предпочтения пользователей;
   - вес ребра - количество пользователей, которым понравилась соответствующая пара фильмов.

Ожидаемые характеристики графа:

- 410 узлов;
- 14 936 ребер.

## Основная идея

Фильмы, которые нравятся одним и тем же пользователям, считаются структурно близкими в графе. После обучения Node2Vec такие фильмы должны получать похожие векторные представления, которые можно использовать для поиска ближайших соседей и формирования рекомендаций.

## Ожидаемый результат

В результате работы необходимо получить:

- построенный граф связей между фильмами;
- обученные Node2Vec-эмбеддинги фильмов;
- функцию рекомендации похожих фильмов;
- примеры рекомендаций для нескольких фильмов;
- краткий анализ влияния параметров Node2Vec на качество рекомендаций.
